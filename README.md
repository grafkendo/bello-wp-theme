# Bello — WordPress child theme (Astra)

Brand theme for [Bello](https://bellolist.com) ("Des Moines' verified pros"), the AI-native local home-services directory.

- Parent theme: [Astra](https://wpastra.com/)
- Palette: navy `#002244` · orange `#FB4F14` · ink `#0A1628` · paper `#FAF6EE`
- Type: Sora (display) + Inter (body) via Google Fonts
- Includes homepage block styles (`.bello-ticket`, `.bello-kicker`, `.bello-steps`, `.bello-promise`, `.bello-band`) matching the bellolist.com landing page

## Deploy

```bash
cd /path/to/wp-content/themes
git clone https://github.com/grafkendo/bello-wp-theme.git bello
```

Updates: `cd bello && git pull` — no more zip uploads.
